About the 8-Puzzle

The 8-Puzzle is a classical artificial intelligence problem consisting of eight numbered tiles and one blank space arranged on a 3 × 3 board. The objective is to move the tiles into a specified goal configuration.

The problem can be represented as a state-space search problem. Each arrangement of the tiles represents a state, while moving the blank tile generates a successor state.

State

A particular arrangement of the eight tiles and blank space.

Actions

Moving the blank tile up, down, left or right.

Goal

Reach the specified goal arrangement of the puzzle.

A* Search Algorithm

Description

A* is an informed search algorithm that combines the actual cost of reaching a state with an estimated cost from that state to the goal.

Evaluation Function

f(n) = g(n) + h(n)
  • g(n): Cost from start to node
  • h(n): Estimated cost to goal
  • f(n): Total estimated solution cost

Working Principle

  1. Insert the initial state into the open list.
  2. Select the node with the smallest f(n).
  3. Expand the selected node.
  4. Generate its valid successor states.
  5. Calculate g(n), h(n), and f(n).
  6. Continue until the goal is reached.

Misplaced Tiles

Counts the number of tiles that are not in their correct goal positions.

h(n) = Number of misplaced tiles

The blank tile is not included in the calculation.

Manhattan Distance

Calculates the total horizontal and vertical distance of each tile from its goal position.

h(n) = Σ(|row - goalRow| + |column - goalColumn|)

Advantages

  • Efficient informed search
  • Can find optimal solutions
  • Uses domain knowledge
  • Manhattan distance performs well for 8-Puzzle

Limitations

  • Can consume significant memory
  • Performance depends on heuristic
  • Large state spaces can be expensive

Complexity

Time: O(bd)

Space: O(bd)

Complete: Yes, under standard finite-branching and positive-cost assumptions.

Optimal: Yes, when using an admissible/consistent heuristic.
